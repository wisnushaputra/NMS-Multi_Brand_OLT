# Product Requirements Document: NMS Web

## Objective
NMS Web untuk ISP: monitoring, konfigurasi, provisi OLT terpusat.

## Fitur Utama
1. **Multi-Vendor Adapter**: ZTE, Huawei, Fiberhome.
2. **Otomasi Provisi**: Registrasi ONU, mapping port, VLAN, PPPoE.
3. **Monitoring**: Topologi, status perangkat, notifikasi gangguan.
4. **Audit Log**: Pencatatan aktivitas.
5. **Integrasi**: GenieACS, external tools.
