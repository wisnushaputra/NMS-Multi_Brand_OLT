# STYLEGUIDE.md

## General
- Bahasa: Indonesia.
- Format: Markdown.
- Indentasi: 4 spasi untuk kode.

## Kode
- Naming Convention: `snake_case` untuk variabel, fungsi, dan nama file. `PascalCase` untuk kelas.
- Komentar: Jelas, ringkas, dan hanya jika perlu.

## Dokumentasi
- Endpoint API: Gunakan format OpenAPI.
- Database: Diagram ERD diutamakan.

## UI/UX
- Konsistensi: Gunakan komponen UI yang sama di seluruh aplikasi.
- Simplicity: Antarmuka bersih, intuitif.
- Responsiveness: Desain adaptif untuk berbagai ukuran layar.
